# Overrides do projeto

Conteúdo específico deste projeto, com a mesma estrutura de `kit/`:
`agents/`, `skills/`, `rules/`, `commands/`, `templates/`.

Um item com o mesmo nome de um item do kit o substitui. Depois de editar, rode `sdd sync`.
Nunca edite `.claude/` ou `.cursor/` diretamente: são gerados.
